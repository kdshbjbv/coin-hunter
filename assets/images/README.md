# 可选图片资源

没有图片也能运行，游戏会使用内置图形。只需把自己的图片放到本目录：

| 文件名 | 游戏显示尺寸 | 建议 |
| --- | --- | --- |
| player.png | 64 × 32 | 透明背景，尽量减少透明留白 |
| coin.png | 24 × 24 | 透明背景，主体位于中央 |
| obstacle.png | 48 × 36 | 透明背景，尽量填满碰撞区域 |
| background.png | 800 × 600 | 不透明背景 |

图片会自动缩放到显示尺寸，因此建议使用相同比例。替换图片后关闭并重新启动程序。
同一文件和尺寸只读取、缩放一次；按 R 重开仍使用当前程序已经缓存的资源。
缺失图片直接回退，损坏图片会记录提示并使用默认图形，不中断游戏。
四种图片可以分别替换，无需一次提供全部图片。

图片只影响绘制，碰撞仍使用原有矩形。金币的碰撞矩形为圆形外接矩形，
玩家和障碍的碰撞区域为完整显示尺寸，不按透明像素检测。
自定义玩家图片在受伤时会显示红色版本，并保留透明度。
背景图片的透明部分会显示默认背景，避免透明区域残留上一帧画面。
